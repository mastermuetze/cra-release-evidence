# Security policy

## Supported version

No version has been released yet. After the first `0.1.x` release, only the latest published `0.1.x` version is intended to receive security fixes during the prototype phase.

## Reporting a vulnerability

Report suspected vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/mastermuetze/cra-release-evidence/security/advisories/new). The repository owner must enable that GitHub feature before the first source push; if the link is unavailable, do not disclose the report publicly and wait until a private channel is announced.

Do not disclose vulnerabilities, exploit details, private SBOMs, tokens, source code, or customer information in public issues or pilot registrations.

## Expected response policy

A private report creates a draft security advisory visible to the repository's security managers. No acknowledgement or remediation service level is promised for the source-only prototype. The publisher must define a monitored security owner, acknowledgement target, update cadence, and coordinated disclosure process before `v0.1.0` is listed. Until those commitments exist, the Marketplace preflight remains blocked.
